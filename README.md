## Featured Projects

### 🎫 Helpdesk Ticket System

A web-based helpdesk application for creating and managing support tickets.

**Technologies:** Python, Flask, SQLite, HTML, CSS, Jinja

**Features:**

* Create, view, edit, and delete support tickets
* Change ticket status between `Open`, `In Progress`, and `Closed`
* Assign `Low`, `Medium`, or `High` priority
* Filter tickets by status
* Store data in SQLite
* Validate user input on the server
* Handle invalid ticket IDs
* Automatically store ticket creation date and time
* Responsive ticket card interface

**What I practiced:**

* Flask routes
* GET and POST requests
* HTML forms
* Jinja templates
* SQLite and SQL
* CRUD operations
* Server-side validation
* Working with URL parameters
* Connecting backend logic with a web interface

[View Helpdesk Ticket System](helpdesk_app/README.md)

### 🌤️ Weather App

A command-line application that retrieves current weather information using the OpenWeather API.

**Technologies:** Python, Requests, OpenWeather API, JSON

**Features:**

* Search weather by city
* Display city and country
* Show local date and time
* Display temperature and feels-like temperature
* Show weather conditions, humidity, and wind speed
* Search multiple cities without restarting
* Handle invalid cities and API errors
* Handle connection errors and timeouts
* Keep the API key outside the source code

**What I practiced:**

* HTTP GET requests
* External APIs
* JSON responses
* HTTP status codes
* Exception handling
* Request parameters
* Unix timestamps and time zones
* Input validation
